# Demo

[Watch the video](riddlemaster-demo.mp4)

A real run with a [public missing-number puzzle](https://x.com/IntEngineering/status/2039840381387317491):

1. A puzzle link arrives in the native HelloMinds chat.
2. The workspace saves the source and displays competing interpretations.
3. The player selects the row-rule hypothesis.
4. The Mind checks it and saves **8** as a possible answer, while retaining the alternative **1**.

The video uses actual browser captures; waiting and navigation pauses are shortened. The selected branch is not presented as a verified solution. The Mind also corrected a mistyped investigation link in the recorded conversation.

[Sanitized run trace](trace.json) includes real protected calls and native messages, with account identifiers, credentials and local case links omitted. First-time setup on another real account is still unverified.
